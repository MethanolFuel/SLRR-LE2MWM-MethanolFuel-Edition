# Parts data model (`src/Slrr.Engine.Parts`)

Phase 3 wave 2, area **Parts**: the native state behind `java.game.parts.Part`, `bodypart.Chassis`, `WheelRef`, `SfxTable`,
`DynoData` and `java.lang.RawEdit`, registered as one `INativeModule` (`PartsNatives`). Data model only: every value the
scripts push is stored and exposed; **no physics** (wear accumulation, suspension, dyno curve) is computed here.

Labels: **M** = measured (exe strings/registrations, shipped cfg/class data, or observed by running the shipped scripts in
our VM), **G** = guessed (chosen so the shipped scripts work; needs a trace of the original, see
[open-questions.md](../engine-api/open-questions.md)).

* **Driven scripts** (tests `ScriptDrivenTests`, `RawEditAndNativeTests`): Baiern DevilSport chassis from `_main_DevilSport.cfg`
  (4 wheels at the cfg `wheel` positions, mass 803.5 kg = the cfg's own "total mass" comment); KSport GT Pro shock installed by
  the script `command("install 0 car 0 parent 304")` -> `getWheelID()==3`, `updatevariables()` sets render type and pushes damping

  DevilSport front swaybar sends `add_rollbar 0 1 25000 2500`; Einvagen 110 GT block + `Chassis.updatevariables()` +

## Behaviour, measured vs guessed

### Part twin

| Behaviour | Label |
|---|---|
| Native names/descriptors, the `getSlotID(-1)` convention, index-based `getSlotDamage/setSlotDamage` (Part.save/load use slot indices) | M (class files, exe table, script code) |
| Wear/tear default 1.0 for a new part; setters (`setWear`, `setTear`, `setTexture`, `setMesh`, `setRenderType`) return the previous value | G (no script uses the result) |
| `setMaxWear` only stores the lifespan; wear never changes on its own | G (accumulation is physics) |
| `getSlots` = number of cfg slots; slots unknown to the cfg are created on demand by `setSlotPos`/`disableSlot`/explicit links | M count / G on-demand |
| `getSlotDamage` = null when undamaged | G (Part.save only writes non-null texts) |
| `flap(0)` queries, `flap(1)` toggles, returns the state | G (Part.getFlap/toggleFlap) |
| `getCar()` = car id after `install`, 0 when loose or for a loose chassis; `getCarRef()` = car chassis, a chassis answers itself | G |
| `getWheelID()` = corner of the chassis slot the subtree hangs from: last digit 1..4 of that slot's `slottype`, else of its id; -1 when loose | G (pattern measured in all car cfgs: 101..104, 111..114, 201..204, 301..304 ...) |
| `partOnSlot`/`slotIDOnSlot` symmetric: on the child's mount slot they return the parent and the parent's slot id | M (Vehicle.isTestable: `seat.slotIDOnSlot(1) == 901`) |
| `getMass` (Part, undeclared) = sum of the cfg `body` masses; `getLogo` native returns `manufacturer` (the script method shadows it) | G |
| `install_OK(car, slot, outRef, ?, pos)` returns `{parentSlotId, childSlotId}` for the first free compatible slot in the car tree (depth first), binds `outRef` to the target part, null if none | G (layout unknown, P0 #5) |

### Linking (`install` / `remove` / `repair` commands)

`GameRef.command(s)` is script code: `queueEvent(null, EVENT_COMMAND, s)` (M). The GameRef owner should hand EVENT_COMMAND (16)
events whose target is a Part to `PartsWorld.ExecuteCommand(vm, target, text)`; it returns false for verbs it does not own.

* `install f car childSlot parentPart parentSlot [x y z]`: token roles M (exe parser 0x475f6d). parentPart 0 = search the car's
  tree; parentSlot 0 = let the engine choose (G: first free enabled pair in slot order); drop position ignored (G).
* Link rule (G, P0 #5): parent slot `attach (childType, childSlot)`; or child slot `attach (parentType, parentSlot)`; or the child
  slot (or the whole part, for part-level lines) is `compatible (T, S)` with a `(T, S)` the parent slot attaches (aftermarket shock
  `compatible 0x00041000 1` vs car slot 301 `attach 0x00041000 1`), or whose own definition attaches to the parent slot
  (needs `PartsWorld.DefinitionOf`). An explicit parent slot without any cfg rule on either side is accepted (G). `ForceLink` links
  two explicit slots without rules (save loaders, garages that resolved the drop).
* After a link: `parent.addpart(child)` then `child.install()`; after an unlink `parent.rempart(child)` then `child.remove()` (names M
  from the exe string table, order G; `PartsOptions.InvokeScriptCallbacks`). The car pointer of the whole subtree follows the link.
* `remove`: unlink from the parent (the part goes back to the map: map placement is not this area's). `repair`: clears slot and wheel
  damage texts (G). `add_rollbar w1 w2 force damping` on a chassis stores a rollbar per wheel pair (verb/arguments M from Swaybar,
  replacement on repeat G).

### Chassis

| Behaviour | Label |
|---|---|
| The 23 contract fields and 39 DynoData names (`ChassisParams.FieldNames`, `DynoParams.FieldNames`) | M (exe string xrefs) |
| `forceUpdate()` snapshots them into `ChassisState.Params` and raises `PartsWorld.ChassisUpdated`; skipped while `suspend_update != 0` | G (suspend_update is the first name the routine reads) |
| Wheel corners = cfg `wheel` lines (4 on every shipped car), position/orientation/radius (`type .. sphere r`) from the cfg; 4 empty corners without a cfg | M count/positions, G radius role |

| `getMass` = sum of `body` masses (equals the importer's `# total mass` comment); `getCM` mass-weighted body centre; `getMin/getMax` = body-centre bounds | M mass / G CM, bounds (mesh bounds belong to the geometry layer; overridable) |
| `getSfxTable(n)` one table per channel, created on demand; `addItem/AddItemPtr` append, `clear` empties, `getItems` counts; AddItemPtr returns the item number | G |
| `setHornSFX/setNitroSFX/setSteerWheel/setSteerWheelRadius/setCooling/setBuck/setAckermann/setTorque/setSfxExhaustMinVol/setMileage/setWheelDamage` stored verbatim | G (no consumer yet) |
| `getTorque(rpm, boost)` and `DynoData.calcDyno/getTorque/getHP` route to `IDynoCalculator`; the default `NullDynoCalculator` leaves the DynoData fields as the scripts set them and returns 0 | placeholder (physics, Phase 4) |
| `getIndexedData(i)` returns the float view of the 32-bit cell at offset i of `ChassisTelemetry` (GearNumber is an int: its float view is "strange", as the source comment says); `getIndexedAddr(i)` = handle `0x20000000 | serial<<16 | i` | M offsets/names (Chassis.java), G handle |

### WheelRef

Every setter stores into `WheelState` (M names, G roles beyond them). `setDamping(F)` sets bump = rebound; `setDamping(FF)` = (bump,
rebound) (G order). `setPacejka(i, v)` ignores i outside 0..14. `getSteer/setSteer` and `RawEdit` at `ptr + 0xC8` are the same field
(M identity, rawedit.md). Handles: `0x40000000 | serial<<12`; other offsets written through RawEdit are kept raw so reads match writes (G).

### RawEdit shim (rawedit.md section 4)

* `RawAddressMap`: 69 addresses -> typed `EngineSettings` properties (8 groups), generated from the research TSV (test
  `AddressMapMatchesTheResearchTable`). Presets: `EngineSettings.MethanolFuel()` = values patched into Slrr_GI (M) and
  `EngineSettings.Vanilla()` = Redline file values for the 25 config-backed globals (M); mod variables keep the GI value (G).
* `getI/getF/setI/setF` keep the exe's untyped 32-bit semantics (getI on a float cell returns its bits, M: plain mov/fld);
  `setI/setF` return the address (M). Derived `CarDeformationOnCollisionMultMinus` = `-BodyDeformationMult`, writes ignored;
  read-only host counters (`*_current`, clocks) ignore script writes (G per rawedit.md). Unknown addresses: logged once in
  `PartsWorld.Diagnostics`, read 0, writes dropped.
* Wheel (`ptr+0xC8` = steer) and telemetry handles are decoded before the absolute table; telemetry cells writable by scripts:
  GearNumber, Flags, SpeedLimit (rawedit.md rule 4), others read-only.
* `CentCur` calls `PartsWorld.CenterCursor` (window layer), default returns 0.
* **File.exists contract:** `HeadlightController` tests `File.exists("system\\Scripts\\lang\\RawEdit.class")` as `hasExhaustiveBits`.
  The file is shipped (test asserts it exists in the game root); the java.io owner must keep `File.exists` answering from the game
  file system so the flag stays true.

## Integration points for other areas (interfaces defined here, no other area's internals assumed)

| Need | Owner | Hook |
|---|---|---|
| Part creation from a gametype (`GameRef.create`, `createFromFile`) | Resources/instances | call `World.Attach(obj, PartDefinition.FromCfg(cfg, typeId, resolveTypeId), typeId)` after `NewObject`, before `<init>(int)` |
| cfg type ids -> runtime ids, gametype id -> definition | Resources | `resolveTypeId` argument of `FromCfg`; `World.DefinitionOf` |
| `GameRef.id()`, id -> object, GameRef handle binding (`install_OK` out ref, `getScriptInstance`) | Resources | implement `IPartHost` (`IdOf`, `Resolve`, `Bind`, `PartBehind`); `DefaultPartHost` uses `VmObject.Id` and a binding table (`BoundTarget`) |
| `GameRef.queueEvent(.., EVENT_COMMAND, text)` on a part | Resources/game | `World.ExecuteCommand(vm, target, text)` first, own verbs if it returns false |
| `GameRef.getInfo(key, arg)` on a part | Resources/game | `World.TryGetInfo(obj, key, arg, out v)`: GII_TYPE 6 -> type id, GII_CATEGORY 7 -> GIR_CAT_PART 9, GII_PART_OWNER 43 -> car id, GII_PART_CATEGORY 55 -> cfg category, GII_REMOVE_OK 41, GII_INSTALL_OK 71 / GII_COMPATIBLE 72 (arg = other instance id) -> 1/0. Key numbers M (GameType constants), answers G (P0 #6) |
| Physics consumers | Phase 4 | `ChassisState.Params` / `ChassisUpdated`, `WheelState`, `EngineSettings`, `IDynoCalculator` |

The test harness (`tests/Slrr.Engine.Parts.Tests/Harness.cs`) contains deliberately trivial test-only stand-ins for those
other-area natives (ResourceRef handles, `getScriptInstance`, `getInfo`, `queueEvent`) and stubs every remaining native.
